I also have built an offline Hacker knowledge research platform named H.A.N.K (Hackers Archive of Nefarious Knowledge) that runs on a raspberry pi. 
It uses a structured workflow where research materials are ingested, converted to Markdown, reviewed, and then indexed using Qdrant for both full-text and semantic search. The system integrates Ollama for local language model interactions and Open WebUI as an initial interface, allowing users to query their knowledge base with both exact text matching and semantic understanding while maintaining source provenance and version control through Git
